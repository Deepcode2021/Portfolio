BUILDING A FULL CRUD STUDENT MANAGEMENT CLI IN PYTHON

DATE: OCT 2026

TAGS: #PYTHON #CLI #GSOC2027 #OPEN-SOURCE

As part of my initial preparations to start contributing to GSoC 2027, I decided to build a foundational project to sharpen my Python skills. The result is a straightforward, lightweight Student Management Command Line Interface (CLI).

This project focuses on executing core CRUD operations smoothly within the terminal without relying on heavy GUI frameworks. It is a simple start, but a necessary stepping stone for larger open-source contributions.

[1] FEATURES EXECUTED

While the feature set is intentionally minimal right now, it handles all standard database operations directly from standard input:

  • ADD: Register new students into the system.
  • SEARCH: Query the records to find specific student details.
  • UPDATE: Modify existing student information seamlessly.
  • DELETE: Remove student records from the database.

[2] INSTALLATION & USAGE

Getting the CLI running on your local machine is very simple. Just clone the repository and execute the main Python script. 

git clone https://github.com/Deepcode2021/student-managment-cli.git
cd student-managment-cli
python3 main.py

[3] SOURCE CODE

The complete source code is available on my GitHub. I plan to add more features over time as I continue preparing for GSoC.
